# Cloud Solutions Lab Guides

Welcome. This site hosts hands-on labs that walk you through configuring and using
cloud collaboration solutions. Each lab is self-contained: it tells you what you need
before you start, gives you numbered steps, and ends with a way to prove the work
succeeded.

## How these labs work

| Element | What it means |
| --- | --- |
| **Task** | A chapter of the lab. Complete tasks in order. |
| **Step** | A single numbered action. Do exactly what it says. |
| :material-check-circle: **Verify your work** | A checklist at the end of each task. Don't move on until every box is true. |
| !!! note | Background context. Useful, not required. |
| !!! warning | Something that will cost you time or licenses if you get it wrong. |

## Conventions used throughout

- **Bold** text is a literal UI element you click or select — for example, click **Add user**.
- `Monospace` text is something you type, or a value shown on screen.
- ++ctrl+c++ style markers are keyboard keys.
- Any value written as `<placeholder>` must be replaced with your own value.
